How billing works

Applied at check-out

  1. 1

    Parking time is rounded up to the next {{ form.controls.roundingMinutes.value }}-minute block.

  2. 2

    The first hour costs {{ formatCurrency(form.controls.firstHourRate.value) }}.

  3. 3

    Each additional started hour adds {{ formatCurrency(form.controls.additionalHourRate.value) }}.

  4. 4

    Every 24-hour block is capped at {{ formatCurrency(form.controls.dailyRate.value) }}.

Sessions up to {{ form.controls.graceMinutes.value }} minutes are free. Saved changes apply to check-outs completed after the update.

Integrity notes

  • Amounts are never accepted from the browser.
  • Entry and exit timestamps come from the server clock.
  • The daily cap limits every partial 24-hour block.
